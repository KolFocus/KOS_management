#需求1：KOS 管理模块

#涉及表《配置_小红书专业号_kos列表》:
建表 SQL：
```sql
CREATE TABLE IF NOT EXISTS `配置_小红书专业号_kos列表` (
  `品牌` TEXT NULL,
  `品牌ID` VARCHAR(64) NOT NULL,
  `用户ID` VARCHAR(64) NOT NULL,
  `昵称` TEXT NULL,
  `头像` TEXT NULL,
  `排序` VARCHAR(4) NULL,
  `所属用户` TEXT NULL,
  `所属店铺` TEXT NULL,
  `渠道` VARCHAR(64) NULL,
  `参与统计` TINYINT(1) NULL,
  `AZ_批次号` VARCHAR(64) NOT NULL,
  PRIMARY KEY (`品牌ID`, `用户ID`)
) COMMENT='KOS 专业号配置列表';
```
#涉及表《品牌离线导入_kos销售数据》:
建表 SQL：
```sql
CREATE TABLE IF NOT EXISTS `品牌离线导入_kos销售数据` (
  `品牌` TEXT NULL,
  `品牌ID` VARCHAR(64) NULL,
  `周期类型` VARCHAR(64) NULL,
  `日期` VARCHAR(64) NULL,
  `短日期` VARCHAR(64) NOT NULL,
  `员工姓名` VARCHAR(64) NULL,
  `店铺编号` VARCHAR(64) NULL,
  `小红书成单` DOUBLE(12,2) NULL,
  `本期累计成单` INT NULL,
  `企微留资数` INT NULL,
  KEY `idx_品牌ID` (`品牌ID`),
  KEY `idx_周期类型` (`周期类型`),
  KEY `idx_日期` (`日期`),
  KEY `idx_店铺编号` (`店铺编号`),
  KEY `idx_员工姓名` (`员工姓名`)
) COMMENT='品牌离线导入 KOS 销售数据';
```

#功能1 配置_小红书专业号_kos列表 列表（简称：kos列表）
1. 功能描述：
   1.1 列表展示(展示所有字段)
   1.2 关联用户(通过用户ID进行修改头像、所属用户、所属店铺、排序、渠道)
   1.3 上下线(通过修改 参与统计字段（1：上线 2:下线)

#功能2 品牌离线导入_kos销售数据 列表（简称：kos销售列表）
1. 功能描述：
   1.1 列表展示(展示所有字段)
   1.2 添加更新(通过Excel进行数据添加,如果存在则覆盖)
