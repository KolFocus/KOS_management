# 功能描述
功能名称：kos推广筛选

通过调用 supabase函数 进行数据获取
调用示例：
SELECT *
FROM get_kos_promotion_dashboard(
  ARRAY['518b6fbf-a09e-4ade-84de-c993c6954b3f','5e7b1a4d00000000010002b6','670894cbff158e0015b63ff5'],
  '2025.10.01'::date,
  '2025.10.01'::date,
  '2025.10.01'::date,
  '2025.10.01'::date
);

 返回列：
 所属用户_out	所属店铺_out	渠道_out	note_url_out	cover_image_out	note_id_out	发布日期_out	互动量_out	预估阅读数_out	互动率_out	笔记投广消耗_out
