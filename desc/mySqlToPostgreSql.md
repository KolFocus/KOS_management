# MySQL → PostgreSQL 一键转译指令

## 一句话任务
请将下方 MySQL 方言 SQL 完整改写为 **PostgreSQL 15** 语法，确保可直接在 Supabase 执行，并严格遵循下列「必改清单」。

---

## 必改清单（checklist）
| 序号 | MySQL 写法 | PostgreSQL 写法 |
|---|---|---|
| 1 | `` `标识符` `` | `"标识符"` |
| 2 | `IF(expr,a,b)` | `CASE WHEN expr THEN a ELSE b END` |
| 3 | `STR_TO_DATE(d,'%Y-%m-%d')` | `d::date` 或 `TO_DATE(d,'YYYY-MM-DD')` |
| 4 | `DATE_FORMAT(d,'%Y-%m-%d')` | `TO_CHAR(d,'YYYY-MM-DD')` |
| 5 | `GROUP_CONCAT(col,',')` | `STRING_AGG(col,',')` |
| 6 | `AUTO_INCREMENT` | `SERIAL` 或 `GENERATED BY DEFAULT AS IDENTITY` |
| 7 | `LIMIT 10 OFFSET 20` | 保持不变 |
| 8 | `REGEXP` / `NOT REGEXP` | `~` / `!~` |
| 9 | `ON DUPLICATE KEY UPDATE` | `ON CONFLICT (pk) DO UPDATE SET ...` |
|10 | `UPDATE a JOIN b ON ... SET a.col=b.col` | `UPDATE a SET col=b.col FROM b WHERE a.key=b.key` |
|11 | `DELETE a FROM a JOIN b ON ...` | `DELETE FROM a USING b WHERE a.key=b.key` |
|12 | `NOW()` / `CURDATE()` | `NOW()` / `CURRENT_DATE` |
|13 | `UNIX_TIMESTAMP()` | `EXTRACT(EPOCH FROM NOW())` |
|14 | `FROM_UNIXTIME(ts)` | `TO_TIMESTAMP(ts)` |
|15 | 关键字冲突标识符 | 一律加双引号，如 `"user"`、`"order"` |
|16 | 日期文本比较 | 文本列先转 `date`：`"日期"::date &gt;= '2025-09-01'::date` |

---

## 输出要求
1. 仅返回 **改写后的完整 PostgreSQL 代码**，无需解释步骤。  
2. 确保 **无反引号**、**无 MySQL 函数残留**。  
3. 函数/视图请加 `CREATE OR REPLACE FUNCTION/ VIEW ... LANGUAGE sql`。  
4. 中文列名保留双引号；其余可去引号用小写。  
5. 所有日期转换统一用 `::date` 或 `TO_DATE()`。

---

## 使用示例（可删除）
```sql
-- 原始 MySQL
SELECT `user_id`, IF(`status`=1,'活跃','冻结') AS state
FROM `user`
WHERE created_at &gt;= '2025-01-01';

-- 期望 PostgreSQL
SELECT "user_id", CASE WHEN "status"=1 THEN '活跃' ELSE '冻结' END AS state
FROM "user"
WHERE created_at::date &gt;= '2025-01-01'::date;
