# 框架使用说明

## 项目概述

本项目是一个基于KOS（Key Opinion Sales）管理系统的后端管理系统，主要用于管理小红书专业号的KOS列表和销售数据。

## 技术架构

### 前端技术栈
- **框架**: Vue 3
- **UI组件库**: Element Plus
- **构建工具**: Vite
- **状态管理**: Pinia
- **路由管理**: Vue Router

### 后端技术栈
- **框架**: Supabase (PostgreSQL)
- **API**: Supabase REST API
- **认证**: Supabase Auth
- **实时功能**: Supabase Realtime
- **存储**: Supabase Storage

## 核心功能模块

### 1. KOS管理模块
- **KOS列表管理**: 管理小红书专业号的KOS列表
- **用户关联**: 通过用户ID关联用户信息
- **上下线管理**: 控制KOS的参与统计状态

### 2. 销售数据管理模块
- **销售数据列表**: 展示KOS销售数据
- **Excel导入**: 支持通过Excel批量导入销售数据
- **数据更新**: 支持数据的添加和覆盖更新

## 开发规范

### 代码规范
- 遵循Vue 3 Composition API最佳实践
- 使用TypeScript进行类型检查
- 使用ESLint和Prettier进行代码格式化
- 编写完整的注释和文档

### 数据库规范
- 表名使用中文描述，便于业务理解
- 字段命名采用驼峰命名法
- 合理设置索引提高查询性能
- 使用Row Level Security (RLS)进行数据安全控制

### API规范
- 使用Supabase REST API
- 统一的响应格式
- 完善的错误处理机制
- 支持实时数据订阅

## 部署说明

### 开发环境
1. 安装Node.js 16+
2. 安装Supabase CLI
3. 配置Supabase项目连接
4. 启动前端开发服务器
5. 连接Supabase数据库

### 生产环境
1. 构建前端项目
2. 部署到Supabase
3. 配置域名和SSL证书
4. 设置环境变量
5. 配置监控和日志

## 注意事项

1. Supabase API密钥为敏感信息，请妥善保管
2. 生产环境部署前请修改默认配置
3. 定期备份数据库数据
4. 监控系统运行状态和性能指标
5. 使用环境变量管理敏感配置信息
