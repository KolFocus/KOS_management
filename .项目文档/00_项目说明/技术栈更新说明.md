# 技术栈更新说明

## 更新概述

根据desc目录下的最新文档要求，已将KOS管理系统的技术栈从Spring Boot + MySQL调整为Vercel + Supabase的现代化架构。

## 技术栈对比

### 原技术栈
- **前端**: Vue 3 + Element Plus
- **后端**: Spring Boot + MyBatis Plus
- **数据库**: MySQL 8.0
- **部署**: 传统服务器部署

### 新技术栈
- **前端**: Vue 3 + Element Plus + TypeScript
- **前端部署**: Vercel
- **后端服务**: Supabase (PostgreSQL + Auth + Storage)
- **数据库**: Supabase PostgreSQL
- **认证**: Supabase Auth
- **存储**: Supabase Storage

## 主要优势

### 1. 开发效率提升
- **无服务器架构**: 无需管理服务器和数据库
- **自动扩展**: 根据流量自动扩展
- **实时功能**: 内置实时数据同步
- **类型安全**: TypeScript提供完整的类型支持

### 2. 成本优化
- **免费额度**: Supabase和Vercel都提供慷慨的免费额度
- **按需付费**: 只为实际使用的资源付费
- **无运维成本**: 无需专门的运维人员

### 3. 安全性增强
- **Row Level Security**: 数据库级别的安全策略
- **JWT认证**: 现代化的认证机制
- **HTTPS**: 自动SSL证书
- **CORS保护**: 内置跨域保护

### 4. 性能优化
- **全球CDN**: Vercel的全球CDN加速
- **边缘计算**: 就近访问，降低延迟
- **自动优化**: 图片和资源自动优化

## 部署流程

### 1. Supabase部署
```bash
# 安装Supabase CLI
npm install -g supabase

# 初始化项目
supabase init

# 链接到远程项目
supabase link --project-ref your-project-ref

# 运行数据库迁移
supabase db push
```

### 2. Vercel部署
```bash
# 安装Vercel CLI
npm install -g vercel

# 部署前端
vercel --prod
```

### 3. 环境配置
```bash
# 前端环境变量
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```
