# 技术方案

## 技术架构概述

本项目采用现代化的全栈架构设计，前端使用Vue 3 + Element Plus部署到Vercel，后端使用Supabase提供数据库、认证和API服务。

## 整体架构图

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   前端应用      │    │   Supabase      │    │   数据库        │
│   Vue 3         │◄──►│   PostgreSQL    │◄──►│   PostgreSQL    │
│   Element Plus  │    │   Auth          │    │   Storage       │
│   Supabase SDK  │    │   Realtime      │    │   Edge Functions│
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

## 前端技术方案

### 1. 技术栈选择
- **Vue 3**: 采用Composition API，提供更好的TypeScript支持
- **Element Plus**: 成熟的UI组件库，提供丰富的组件
- **TypeScript**: 类型安全的JavaScript超集
- **Vite**: 快速的构建工具，支持热更新
- **Pinia**: 状态管理库，替代Vuex
- **Vue Router**: 路由管理
- **Supabase SDK**: 直接调用Supabase服务

### 2. 项目结构
```
frontend/
├── src/
│   ├── components/          # 公共组件
│   │   ├── common/         # 通用组件
│   │   ├── layout/         # 布局组件
│   │   └── business/       # 业务组件
│   ├── views/              # 页面组件
│   │   ├── kos/           # KOS管理页面
│   │   └── sales/         # 销售数据页面
│   ├── router/             # 路由配置
│   ├── stores/             # Pinia状态管理
│   ├── api/                # Supabase API调用
│   ├── lib/                # 第三方库配置
│   │   └── supabase.ts    # Supabase客户端
│   ├── types/              # TypeScript类型定义
│   ├── utils/              # 工具函数
│   ├── assets/             # 静态资源
│   └── styles/             # 样式文件
├── public/                 # 公共资源
├── package.json            # 依赖配置
├── vite.config.ts          # Vite配置
├── vercel.json             # Vercel部署配置
└── env.example             # 环境变量示例
```

### 3. 核心功能实现
- **表格组件**: 基于Element Plus Table封装，支持分页、排序、筛选
- **表单组件**: 基于Element Plus Form封装，支持验证和提交
- **文件上传**: 使用Supabase Storage支持Excel文件上传和预览
- **数据可视化**: 使用ECharts实现图表展示
- **实时数据**: 使用Supabase Realtime实现数据实时同步
- **认证授权**: 使用Supabase Auth实现用户认证和权限控制

## Supabase后端服务

### 1. 技术栈选择
- **Supabase**: 开源的Firebase替代方案
- **PostgreSQL**: 关系型数据库，支持JSON和实时功能
- **Row Level Security (RLS)**: 数据库级别的安全策略
- **Edge Functions**: 服务端函数，支持Deno运行时
- **Supabase Auth**: 用户认证和授权服务
- **Supabase Storage**: 文件存储服务
- **Supabase Realtime**: 实时数据同步

### 2. 项目结构
```
supabase/
├── config.toml             # Supabase配置文件
├── migrations/             # 数据库迁移脚本
│   ├── 001_initial_schema.sql
│   ├── 002_initial_data.sql
│   └── 003_rls_policies.sql
├── functions/              # Edge Functions (可选)
│   └── kos-management/
│       └── index.ts
└── seed.sql               # 种子数据
```

### 3. 核心功能实现
- **自动API生成**: 每个表自动生成REST API
- **实时订阅**: 支持数据变化的实时推送
- **类型安全**: 自动生成TypeScript类型定义
- **数据验证**: 数据库级别的约束和验证
- **文件存储**: 支持文件上传和CDN加速
- **用户认证**: 支持多种认证方式
