## 索引设计

### 1. 主键索引
- 所有表都有主键索引，提高查询效率
- 使用BIGSERIAL作为主键，保证唯一性

### 2. 唯一索引
- 用户名、角色编码、权限编码等字段设置唯一索引
- 防止重复数据插入

### 3. 普通索引
- 经常用于查询条件的字段设置索引
- 如：品牌ID、用户ID、渠道、状态等

### 4. 复合索引
- 多条件查询的字段组合设置复合索引
- 如：(品牌ID, 短日期)、(员工姓名, 短日期)等

## Row Level Security (RLS) 策略

### 1. 启用RLS
```sql
-- 为核心业务表启用RLS
ALTER TABLE "配置_小红书专业号_kos列表" ENABLE ROW LEVEL SECURITY;
ALTER TABLE "品牌离线导入_kos销售数据" ENABLE ROW LEVEL SECURITY;

-- 为系统管理表启用RLS
ALTER TABLE "sys_user" ENABLE ROW LEVEL SECURITY;
ALTER TABLE "sys_role" ENABLE ROW LEVEL SECURITY;
ALTER TABLE "sys_permission" ENABLE ROW LEVEL SECURITY;
ALTER TABLE "sys_operation_log" ENABLE ROW LEVEL SECURITY;
```

### 2. 创建RLS策略
```sql
-- KOS列表表策略
CREATE POLICY "KOS列表_所有人可读" ON "配置_小红书专业号_kos列表"
    FOR SELECT USING (true);

CREATE POLICY "KOS列表_认证用户可写" ON "配置_小红书专业号_kos列表"
    FOR INSERT WITH CHECK (auth.role() = 'authenticated');

CREATE POLICY "KOS列表_认证用户可更新" ON "配置_小红书专业号_kos列表"
    FOR UPDATE USING (auth.role() = 'authenticated');

CREATE POLICY "KOS列表_认证用户可删除" ON "配置_小红书专业号_kos列表"
    FOR DELETE USING (auth.role() = 'authenticated');
```
