# KOS列表管理页面原型设计

## 页面概述

KOS列表管理页面是系统的核心页面，用于展示和管理小红书专业号的KOS列表信息。

## 页面布局

### 1. 整体布局
```
┌─────────────────────────────────────────────────────────────┐
│                        页面头部                              │
├─────────────────────────────────────────────────────────────┤
│  面包屑导航  │  页面标题  │                   操作按钮区域    │
├─────────────────────────────────────────────────────────────┤
│                        筛选区域                              │
├─────────────────────────────────────────────────────────────┤
│                        数据表格                              │
├─────────────────────────────────────────────────────────────┤
│                        分页组件                              │
└─────────────────────────────────────────────────────────────┘
```

### 2. 页面头部
- **面包屑导航**: 首页 > KOS管理 > KOS列表
- **页面标题**: "KOS列表管理"
- **操作按钮**:
  - 新增KOS
  - 批量导入
  - 批量导出
  - 刷新数据

### 3. 筛选区域

## 交互设计

### 1. 列表操作
- **行选择**: 点击复选框选择单行，支持全选
- **排序**: 点击列标题进行排序
- **行操作**: 每行提供编辑、删除、上下线按钮
- **批量操作**: 选择多行后显示批量操作工具栏

### 2. 筛选交互
- **实时筛选**: 输入筛选条件后实时更新列表
- **高级筛选**: 点击高级筛选展开更多筛选选项
- **筛选保存**: 支持保存常用筛选条件
- **筛选重置**: 一键清空所有筛选条件

### 3. 数据操作
- **新增**: 点击新增按钮打开新增对话框
- **编辑**: 点击编辑按钮打开编辑对话框
- **删除**: 点击删除按钮显示确认对话框
- **上下线**: 点击状态按钮切换上下线状态

## 响应式设计

### 1. 桌面端 (≥1200px)
- 表格显示所有列
- 筛选区域横向排列
- 操作按钮完整显示

### 2. 平板端 (768px-1199px)
- 表格隐藏部分次要列
- 筛选区域部分折叠
- 操作按钮部分合并

### 3. 移动端 (<768px)
- 表格改为卡片式布局
- 筛选区域完全折叠
- 操作按钮合并为菜单

## 状态设计

### 1. 加载状态
- **初始加载**: 显示骨架屏
- **数据刷新**: 显示加载动画
- **分页加载**: 显示加载更多按钮

### 2. 空状态
- **无数据**: 显示空数据插画和提示文字
- **筛选无结果**: 显示无结果提示和重置筛选按钮
- **网络异常**: 显示网络错误提示和重试按钮

### 3. 错误状态
- **数据加载失败**: 显示错误提示和重试按钮
- **操作失败**: 显示具体错误信息和处理建议
- **权限不足**: 显示权限错误提示

## 视觉设计

### 1. 色彩方案
- **主色调**: #409EFF (Element Plus 主色)
- **成功色**: #67C23A (上线状态)
- **警告色**: #E6A23C (下线状态)
- **危险色**: #F56C6C (删除操作)
- **信息色**: #909399 (次要信息)

### 2. 字体规范
- **标题**: 16px, 600, #303133
- **正文**: 14px, 400, #606266
- **辅助文字**: 12px, 400, #909399
- **按钮文字**: 14px, 500

### 3. 间距规范
- **页面边距**: 20px
- **组件间距**: 16px
- **表格行高**: 48px
- **按钮间距**: 8px

## 组件规范

### 1. 表格组件
- 使用 Element Plus Table 组件
- 支持固定列和虚拟滚动
- 支持列宽调整和列排序
- 支持行选择和批量操作

### 2. 筛选组件
- 使用 Element Plus Form 组件
- 支持多种输入类型
- 支持表单验证
- 支持条件组合

### 3. 分页组件
- 使用 Element Plus Pagination 组件
- 支持页码跳转
- 支持每页条数设置
- 显示总数和当前页信息

## 动效设计

### 1. 页面切换
- 使用淡入淡出效果
- 切换时间: 300ms
- 缓动函数: ease-in-out

### 2. 数据更新
- 使用高亮效果提示数据变更
- 高亮时间: 2秒
- 颜色: #E1F3D8

### 3. 操作反馈
- 成功操作: 绿色提示
- 失败操作: 红色提示
- 提示时间: 3秒

## 无障碍设计

### 1. 键盘导航
- 支持 Tab 键导航
- 支持方向键选择
- 支持 Enter 键确认

### 2. 屏幕阅读器
- 提供完整的 ARIA 标签
- 描述表格结构和内容
- 提供操作状态反馈

### 3. 色彩对比
- 确保文字与背景对比度 ≥ 4.5:1
- 提供高对比度模式
- 支持色彩盲用户使用
